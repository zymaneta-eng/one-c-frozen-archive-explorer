## 🇺🇦 1. Бізнес-контекст та юридичні вимоги в Україні

### Проблема: Санкції проти російського ПЗ та вимоги Податкового кодексу
Указом Президента України та рішеннями Ради національної безпеки і оборони (РНБО) України застосовано персональні спеціальні економічні та інші обмежувальні заходи (санкції) щодо компаній-розробників та правовласників російських облікових систем («1С», «BAS» тощо). Український бізнес системно виводить ці продукти з промислової експлуатації та переходить на сучасні ERP/CRM-платформи.

Водночас **пункт 44.3 статті 44 Податкового кодексу України (п. 44.3 ст. 44 ПКУ)** категорично зобов'язує платників податків забезпечити гарантоване збереження первинних документів, регістрів обліку та фінансової звітності:
* **Не менше 1 825 днів (5 років)** — для первинних документів, пов'язаних з податковими розрахунками;
* **Не менше 2 555 днів (7 років)** — для первинних документів щодо контрольованих операцій (трансфертне ціноутворення, ст. 39 ПКУ).

### Дилема бухгалтера та фінансового директора:
1. **Не можна тримати 1С активною:** Оплата ліцензій, підтримка підписок ІТС чи утримання вразливих застарілих Windows-серверів порушує корпоративний комплаєнс і створює ризики кібератак.
2. **Не можна видалити базу:** Знищення або недоступність первинних документів під час перевірки ДПС веде до штрафів, невизнання податкового кредиту та зняття витрат компанії.
3. **Хмарні підписки — надлишкові витрати:** Орендувати комерційні хмарні SaaS чи купувати підписки лише заради пасивного архіву за минулі 3–5 років є фінансово недоцільним.

### Рішення: Frozen Archive Explorer
**Frozen Archive Explorer** розв'язує проблему консервації раз і назавжди:
* 🔒 **100% Air-Gapped (Повна ізоляція):** Працює суворо локально (localhost:8020) без доступу до Інтернету. Жодних запитів до зовнішніх CDN, шрифтів чи серверів телеметрії.
* 💸 **Zero-License & Zero-Token:** Нуль витрат на ліцензії 1С/BAS, нуль витрат на платні токени OpenAI/Anthropic.
* 🎯 **Абсолютна фінансова точність:** Усі грошові суми зберігаються та рахуються виключно в цілих копійках (`BIGINT`) без спотворення через арифметику з плаваючою комою (`float drift`).
* ⚡ **Субсекундний пошук (< 50 мс):** Пошуковий рушій SQLite FTS5 з рейтингуванням BM25 повертає результати за 1.5–30 мс за назвою, ЄДРПОУ, номером чи фрагментом коментаря.
* 📦 **Екстремальне стиснення Snappy Parquet:** Десятки тисяч рядків номенклатури та накладних упаковуються в колоночні файли розміром лише 100–150 КБ (стиснення > 95%).
* 📑 **Звітність для податкових перевірок:** Автоматичне формування зведеного **Акта звірки взаєморозрахунків** та офіційного **Реєстру первинних документів для перевірки ДПС**.
* 🖨️ **Друк та експорт:** Готові друковані форми А4 зі сформованою українською мовою «сумою прописом» та вивантаження відфільтрованої вибірки в чистий Excel (`.xlsx`).
* 📜 **Сертифікат незмінності WORM:** Фіксація криптографічних контрольних сум SHA-256 та юридичного протоколу захисту від модифікації даних.

## 🗄️ 3. Модель даних та фінансова точність

### Принцип збереження сум у цілих копійках (`BIGINT`)
У фінансовому обліку використання типів `FLOAT` чи `DOUBLE` неприпустиме через похибки двійкового округлення.
* Сума `1 000,50 ₴` зберігається в базі суворо як ціле число `100050` копійок.
* Сума `62 096 718,00 ₴` зберігається як `6209671800` копійок.
* При відображенні сума ділиться на 100 та форматується за українським стандартом: `62 096 718,00 ₴`.
* Для друкованих форм і картки документа сума конвертується в офіційну суму прописом українською мовою:  
  *Приклад: `62 616,00 ₴` &rarr; «Шістдесят дві тисячі шістсот шістнадцять гривень 00 копійок».*

### Багатоорганізаційний облік (Multi-Company Support)
Архів одночасно веде та розділяє первинні документи декількох юридичних осіб групи:
* **ТОВ «Ареонікс Діджитал» (ЄДРПОУ 43981245):** Платник ПДВ на загальних підставах (ставка 20%, роздільний підрахунок бази без ПДВ та суми податку).
* **ФОП «Ареонікс-Сервіс» (ІПН 3124598712):** Спрощена система оподаткування (єдиний податок, 3 група, статус «Без ПДВ»).

### Підтримувані типи первинних документів:
1. **Видаткова накладна (РН-)** — відвантаження товарно-матеріальних цінностей.
2. **Акт виконаних робіт / наданих послуг (АКТ-)** — підтвердження надання послуг.
3. **Платіжна інструкція / Банківська виписка (ПІ-)** — безготівкові оплати (формують Кредит в акті звірки).
4. **Рахунок на оплату (СФ-)** — замовлення та попередні рахунки.

## 📋 4. Покроковий регламент консервації та виведення 1С

Дотримуйтесь цих 5 кроків для остаточного й безпечного виведення 1С / BAS з експлуатації:

### Крок 1. Експорт даних з 1С / BAS
Зробіть штатне вивантаження з 1С (через зовнішню обробку експорту таблиць або стандартне вивантаження в XML/CSV/JSON/Excel):
* Довідник «Контрагенти» (`counterparties.csv` або `counterparties.json`)
* Журнал документів «Видаткові накладні», «Акти», «Платіжні доручення» (`documents.csv`)
* Табличні частини номенклатури документів (`document_items.csv`)

### Крок 2. Консервація у DuckDB та Snappy Parquet
Запустіть імпортер консервації:
```bash
one-c-importer --json ./data/frozen_archive_bundle.json
```
Імпортер автоматично:
1. Нормалізує копійки та запише первинні записи в `archive_vault.duckdb`.
2. Створить компактні Snappy Parquet бекапи в папці `parquet_vault/`.
3. Побудує пошуковий FTS5 індекс `archive_index.db` з токенізацією українських слів.

### Крок 3. Верифікація контрольних сум та оборотів
Перевірте цілісність завантаженого архіву:
```bash
python -c "from one_c_frozen_archive_explorer.search_engine import SearchEngine; e = SearchEngine(); s = e.get_archive_stats(); print(f'Заморожено документів: {s.total_documents}, Оборот: {s.formatted_total}')"
```

### Крок 4. Зупинка серверів 1C / BAS
* Створіть холодну резервну копію вихідної бази 1С на зовнішній зашифрований накопичувач.
* Вимкніть віртуальні машини та зупиніть сервери 1С, розірвіть договір супроводу ІТС.
* Підприємство повністю відповідає вимогам санкційного законодавства та комплаєнсу!

### Крок 5. Експлуатація архіву та проходження перевірок ДПС
При надходженні запиту від податкової інспекції, аудиторів чи контрагентів запустіть локальний інтерфейс:
```bash
one-c-archive
```
Відкрийте `http://127.0.0.1:8020` у будь-якому браузері на комп'ютері без підключення до мережі.
